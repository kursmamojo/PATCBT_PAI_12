Integrasi Otomatis Google Spreadsheet

Google Apps Script

Setiap kali siswa menekan tombol "Kumpulkan Ujian" atau "Simpan ke Spreadsheet", lembar jawaban akan langsung ditambahkan ke baris baru spreadsheet Bapak/Ibu guru secara realtime.

Panduan 5 Menit Pasang di Google Spreadsheet:
  1. Buka spreadsheet baru di Google Drive (Contoh judul: Nilai CBT PAI XII SMAN 1 Mojo).
  2. Buka menu Extensions (Ekstensi) > Apps Script, hapus kode bawaan, lalu tempel kode di atas.
  3. Klik tombol biru Deploy > New deployment.
  4. Klik ikon gerigi ⚙️ di samping Select type, pilih Web app.
  5. Isi Description (misal: CBT PAI), ganti Who has access menjadi Anyone (Siapa saja), lalu klik Deploy.
  6. Salin Web app URL lalu tempelkan ke kolom URL di atas dan klik Simpan URL Webhook.
